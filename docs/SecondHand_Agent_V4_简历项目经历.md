# SecondHand Agent｜个人闲置交易自主协商卖家助手

Agent 应用开发｜2026.09—至今

**项目简介：** 面向个人闲置交易构建卖家侧协商 Agent，在卖家授权范围内完成商品咨询、多轮议价、人工审批与交易意向确认。

**技术栈：** Python、FastAPI、LangChain、Qwen、MySQL、SQLAlchemy、Vue 3、Docker Compose

- **自主多轮协商：** 针对固定流程难以应对动态议价的问题，实现自主查询、交易条件评估与协商方案调整；在 **120 个合成交易场景、240 次真实模型买卖交互评测**中，交易意向达成率 **56.25%（135/240）**。
- **交易授权与意向确认：** 针对越权定价、伪造审批和未授权履约问题，实现报价授权、人工审批与买家最终确认闭环；同一评测集合中，已执行报价、审批及确认的违规运行 **0/240**。
- **长对话与协商记忆：** 针对历史窗口截断导致早期诉求丢失的问题，实现历史压缩与带来源的协商记忆，覆盖 **超过 20 条公开历史**的长对话交互。
- **执行稳定性与资源控制：** 针对模型循环调用导致持续消耗的问题，实现有限执行与异常兜底；同一评测集合的 **1,122 个卖家轮次**中，**异常执行终止 0 次**。
