## 实现切片

- 新会话固定 `negotiation-v3` / `p4-v1`；原 `negotiation-v1/v2` 保留恢复路径，不改写已有线程。
- 提取式摘要与记忆带来源消息、输入序号、版本和适用范围；模型假设不成为事实或授权。
  原草案完整条件重新从业务表加载，近期历史有界，checkpoint 只持有引用。
- 活动时间跨领取、释放、崩溃、进程重启累计，排队和释放后的退避不计入。
  调用账本覆盖解析、重试、回复、审核、修复，保存请求快照、用途、用量及未知费用预留。
  摘要是确定性提取，不产生隐藏模型调用。默认单输入 10 次、180000 Token、120 秒活动，
  SDK 无隐式重试；请求最多 45 秒，提交后回复期限 45 秒，无模型收尾 15 秒。
- 回复生成与独立审核最多修复两次；结构、覆盖、来源或审核失败不能通过。发布时重验版本，
  并始终保留真实回执及逐项确定性结果，已提交动作不会因为文案失败被重做或否认。
- 新图 Worker 使用可终止子进程，父进程按持久化期限撤销所有权、终止卡死实例、核验线程锁，
  同时轮询独立通知。未经核验的残留数据库会话不被强行绕过。
- 卖家恢复页面及受身份保护的 API：原输入重试、安全终止、待通知重试；请求去重和审计，
  不重置原调用预算，不允许回拨历史输入或丢弃已提交结果。
- LangGraph 根图/节点与 OpenAI SDK 原生追踪使用严格导出客户端，外发仅允许字段和关联摘要；
  错误、附件、原始消息、策略和展示凭据不能外发，异步队列有界。
- 终态至少保留 90 天，活跃输入、审批、待通知、有效展示及待执行 checkpoint 阻止清理。
  按会话标记归档墓碑后才删除 checkpoint；完整审计与幂等记录继续保留，历史请求不可重做。
