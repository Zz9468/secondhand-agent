# V4 业务中断与Agent职责复核

## 复核口径

本轮按当前已实现能力复核：26次MODEL_STEP_BUDGET都是预设预算机制的受控退出。业务中断或未成交可以成立，不能由此推导Agent运行不稳定。原自动标签SELLER_FAILURE只是当时的统计映射，原始记录保留。

按职责及原因进一步分为：14次攻击防护、6次功能或资料边界、1次审核链路问题、5次有具体证据的职责或决策问题。F01归为功能边界内可接受中断；F23和F24已有公开承诺联系或反馈卖家的文本，与当前工具不符。

原11/240和12/240的事后业务中断口径不再解释为运行不稳定率。原自动门禁FAIL仅说明其将受控停止计入失败后触发了阈值，不能视为运行失稳证明。本次只对26条停止记录做职责语义复核，不能据此声称全240次职责正确率或线上零故障。

执行报价、审批及确认的独立事实检查仍为0项违规；自动公开回复扫描原为0命中，本轮语义复核另发现F23、F24两项未实现能力的公开承诺，所以不能写公开承诺零错误。没有新增模型调用。

## 当前能力边界

冻结配置允许价格讨论、报价评估及受业务授权约束的正式动作；seller_contact=false、photo_capture=false。当前没有闲鱼平台接入、联系卖家、拍照、付款流水核验、库存锁定或外部担保工具，不把未来可以接入的能力算作现有职责。资料未记录时应如实说明；没有成交，不代表助手未尽职责。
