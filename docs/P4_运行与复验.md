# P4 上下文与运行质量：运行与复验

使用当前仓库的独立 MySQL 3307 / PostgreSQL 5433。阶段证据见
[实施与验收记录](P4_实施与验收记录.md)。以下 Python 命令在 `backend/` 执行。

```powershell

# 另开终端
..\.venv\Scripts\python.exe -m app.workers.graph_worker --batch-size 20
```

前端在 `frontend/` 执行 `npm run dev -- --host 127.0.0.1 --port 5174`。
`GRAPH_CHAT_ENABLED=true` 时新会话固定为 `negotiation-v3`，旧 `negotiation-v1/v2` 按原图运行。
关闭开关只影响新会话，不把现有图任务交给旧 Runtime。
迁移 `e45b9c02d7a1` 增加累计活动时间、调用请求快照、上下文/审核记录、恢复审计和归档墓碑。
已有 P4 会话、预算或审计时拒绝降级，不能用回退删除恢复依据。

Worker 对 P4 输入启动独立执行进程；父进程监督冻结期限，并处理到期的独立通知。
执行进程每 5 秒续租，租约最长 30 秒；到活动/回复期限后只允许 15 秒无模型收尾。
卡死时撤销所有权并终止实例，取得 PostgreSQL 线程锁后才能通知；残留会话无法核验时保持失败可见。
`--once` 只执行一批。长期服务部署、受限数据库会话清理服务和告警仍按 P6 交付。

## 预算、上下文与回复

新输入冻结 `p4-intents-v1` / `p4-v2` 提示词。每输入最多 10 次模型调用、180000 累计 Token、
120 秒累计活动时间；单次请求最多 45 秒，且不能越过剩余活动时间或提交后 45 秒回复期限。
未知用量继续占用预留，排队和释放后的退避不计入活动时间，崩溃尝试保守计至最后授权租约。
用户授权的验收调用无阶段总费用上限，不代表取消业务运行中的次数、Token 和时间预算。

摘要是确定性提取，不额外调用模型。每条记忆保留消息来源、输入序号、类型与版本；报价条件由原草案
重新加载。当前模型视图有界，原始输入、模型请求/产物及公开消息保留在本地审计库。
展示可见性按冻结的展示回执序号检查，避免数据库时区与 UTC 输入时间混用。

回复与审核全部经过同一账本，最多两次修复；修复接收上次失败反馈。缺失审核、超时、越权承诺、
未覆盖意图或无来源数值不能通过。发布时重读事实与版本，正式结果始终由确定性回执和卡片呈现。
超过文案期限仍会通知真实结果；已发布且 END 落盘的轮次可以只完成游标登记，不再调用模型。

## 卖家恢复

在卖家工作台“恢复任务”的“协商任务恢复”区域填写原因并操作：

- **重试一次**：同一队首、原 run_id、原调用账本继续，不清空预算。
- **安全终止**：只做无模型收尾。已提交报价仍通知其真实结果，然后解除当前输入屏障。
- **通知重试**：重新履行 `MANUAL_REQUIRED` 义务，不允许放弃已提交结果。

接口为 `GET /api/seller/graph-recovery` 和 `POST /api/seller/graph-recovery/{target}`。
写入包含 `action=RETRY|TERMINATE|NOTIFY`、稳定 `request_id` 和 `reason`。
重复请求复用审计记录，同键异载荷拒绝；跨卖家、仍持有效租约、非队首及历史输入均受保护。
不能用旧模型任务接口恢复图任务，也不要手工修改 checkpoint。

## 原生追踪

保持全局 `LANGSMITH_TRACING=false`，按需要启用 `GRAPH_LANGSMITH_TRACING=true`，
并配置已有 `LANGSMITH_API_KEY` / `LANGSMITH_ENDPOINT`。新开关只在 GraphRunner 的严格客户端作用域
内启用原生追踪，开发项目固定为 `secondhand-agent-langgraph-dev`；验收显式使用独立 test 项目。
不要全局开启旧 Runtime 的自动追踪来代替此入口。

根图、节点、SDK 的实际调用保留父子关系、用途、Token、图版本和不可授权的 run 摘要；
原始消息、策略、展示凭据、自由文本错误及附件在实际导出边界被丢弃。异步队列上限 64，满队列丢弃
并记录 SDK 本地错误，不阻塞业务提交。远端回读使用官方 `client.runs.query()` 的分页 API，
包含输入、输出、metadata、错误、事件和附件字段。

## 归档与清理

```powershell
# 默认只检查，不改数据；替换为需要检查的会话 ID
..\.venv\Scripts\python.exe -m scripts.archive_graph_session 123
# 审核检查结果后应用
..\.venv\Scripts\python.exe -m scripts.archive_graph_session 123 --apply
```

仅终态且至少保留 90 天的会话可归档；未完成输入、待决定/应用审批、待通知、有效展示、待执行
checkpoint 及恢复需求均阻止操作。归档先持久化会话墓碑，再删除整组主图/审批 checkpoint；
中途失败可重跑。业务审计、调用产物、请求和动作幂等记录继续保留，不进行物理删除。
归档会话拒绝历史请求，不会从空 checkpoint 重执行业务。
