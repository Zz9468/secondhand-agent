## 冻结协议

| 契约 | 不变量 | 本阶段证据 |
|---|---|---|
| 展示因果（§6.3、§14） | 接收时冻结账号、对象/版本、展示回执；后生成的卡片不能补充旧输入授权；执行时重新检查有效性 | A25 的纯函数与真实 MySQL 输入夹具，A45 重复载荷冲突 |
| 输入顺序（§5.5） | 每会话连续 input_seq；仅 cursor+1 可领取；前序 RETRY_WAIT 保持屏障；同 request_id 不同载荷拒绝 | A27 两个排队输入；A29 历史领取被拒绝 |
| 命令原子性（§6.4、§9.1） | 调用方拥有事务；报价、审批、轮数/版本、回执、通知义务、Outbox 同进同退；稳定来源键与载荷哈希；重放取原回执 | A31 六个写入间隙异常；A16 提交后进程退出 |
| 执行所有权（§9.3） | 顺序为 PG 线程锁→MySQL 租约→业务行锁；saver 与 advisory lock 同一专用连接；不重连旧 runner | 两连接争锁、连接断开、A32 独立监督器 |
| 接管（§9.3） | 先撤销 token/递增代次，再终止子进程，核验 PG 会话已消失后接管；清理须匹配实例 application_name、PID、backend_start、账号、数据库 | 真卡死 30 秒租约；退出/分区故障使用 2 秒测试租约；受限 SQL 清理函数 |
| 恢复入口（§9.4） | 无执行证据且队首才首次输入；本轮 checkpoint 校验 run/seq/input_hash/config_hash/graph_version；有 next 用 invoke(None)，END 仅收尾；较新线程拒绝旧任务回拨 | A29、A30、A46、A60 与跨进程崩溃夹具 |
| 持久性（§9.5） | 所有执行和 Command(resume) 显式 sync；初始 checkpoint 成功先于副作用；成功 sibling 的 pending writes 可重用 | 初始 saver 写失败、并行 sibling 故障与恢复 |
| 模型产物（§9.5） | run+step+input_hash+config_hash 定位产物；重放校验内容哈希；失效所有者的返回仅记尝试审计 | after_model 崩溃恢复仅一产物/尝试；A33 迟到结果拒绝 |
| 追踪（§12.3） | 根图、节点、SDK、metadata、错误和附件均在导出前处理；使用有界队列，失败不阻塞调用 | 本地 HTTP 抓取与远端读回 6 条 trace |

P0 的模型语义是合成固定回调，真实 Qwen 能力另作受预算限制的探测；这避免在重复故障测试中
产生模型费用。组合命令是独立 `p0_*` 表上的最小审批路径，尚未成为生产业务服务。

## 生命周期及业务语义

冻结方案 §7.4 全部转换，P1/P3 必须按表实现：

- `ACTIVE` 的新提案经最终授权计轮；`WAITING_APPROVAL` 的替代/撤回取消当前旧提案。
- 卖家 `APPROVED` 事实与 `effect_status` 分开保存；未应用批准可因替代、撤回、关闭而失效。
- 买家报价已接受但未 `AGREED` 时仍可合法撤回或替代；最终确认后不再改写。
- 旧审批收尾只影响原关联对象，不能把新审批等待改成 ACTIVE；普通咨询不改变审批效力。
- 最终确认同时验证展示因果、当前对象、条款、条件、成本、政策及期限；AGREED/CLOSED 不重新打开。
- 审批响应期限与批准后依据有效期区分；到期/失效保留历史和原因，不删除审计。
- 完整明确的聊天报价可正式提交；预算、比价、未知必要前提、未知成本和未选定备选均不能误提交。

20 条种子标注位于 `backend/evaluation/datasets/p0_semantic_labels.json`，是开发资料，不是
P5 的独立保留集。生产完整状态转换测试仍属 P1/P3，不用这些夹具替代。

## 版本和预算

兼容组合：Python 3.11.16、LangGraph 1.2.12、checkpoint 4.3.0、Postgres saver 3.2.0、
psycopg 3.3.6、LangSmith 0.14.0、OpenAI 3.19.2、Pydantic 2.13.5、OpenEvals 0.2.2、
AgentEvals 0.0.9。完整解析版本在 `backend/requirements.lock`，前端保持既有 package-lock。
MySQL 实测 8.4.11，PostgreSQL 18.6。依赖升级必须重跑对应协议测试。

保留方案初始业务预算：主决策 6 步、总模型 10 次、维护 2 次、工具 8 次、输入 16000 token、
输出预留 3072、累计 180000、活动时间 120 秒、请求至多 45 秒、提交后文案 45 秒、
无模型收尾 15 秒、修复至多 2 次；租约 30 秒、心跳 5 秒、接管目标 90 秒。
这些是待生产接入的上限，不把 P0 探测延迟当作 SLA。

Qwen 探测冻结 `qwen3.7-flash`、temperature=0、thinking=false、SDK retries=0；每批最多
6 次调用/20000 预留 token/0.10 CNY 保守预留，输出限制 512、超时 30 秒。预留费率为北京
短输入公开价的 10 倍，未知用量不退预留。已知费用按输入 0.2、输出 0.8 CNY/百万 token
估计，实际账号账单可能不同。普通对话 P50/P95、并发容量和完整业务成本留到具备主链路后测量；
P5 的风险样本要求保持原值，不能因本阶段少量成功样例下调。
